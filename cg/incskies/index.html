++skies; (Incremented Skies)

ゲーム、映像、イラスト制作を行っている皆様、大きくてフォトリアルな空はいかがですか？ ++skies;は、CGで制作した風景パノラマテクスチャです。HDRiに対応し、最大32k×16kサイズの空であなたのシーンを彩ります。

Naming — ++ について

多くのプログラミング言語において、「++」は「インクリメント演算子」を指し、値に1を加える操作を表します。常に一歩進んだ美しさと解像度を持つ空で、皆様の作品を彩りたいという思いを込めています。

また、これからも一つずつ空を増やし、成長し続けたいという願いも込めています。

++skies;の特徴

FEATURE 01

最大32k (32768px × 16384px) の高解像度

++skies;は、標準の解像度を16kサイズとし、8kサイズの軽量版も用意しています。一部のテクスチャでは、 32k/24k/20kサイズの高解像度版も選択できます。フルHDサイズの作品にも十分な画質を提供します。

FEATURE 02

HDRフォーマットサポート

++skies;は、HDRデータをRadiance形式とOpenEXR形式で、LDRデータをPNG形式で配布しています。HDRのメリットを活かして、IBL素材としてご利用いただくことも可能です。

ダウンロード

パッケージ

++skies;は、フォーマット（Radiance / OpenEXR / PNG / PNG + MMD）と解像度（最大32k〜8k）の組み合わせから選んでご利用いただけます。HDRiのメリットを活かしたい場合は Radiance または OpenEXR を、MMDで利用する場合は PNG + MMD（アクセサリ同梱）をお選びください。利用できる組み合わせは素材ごとに異なります。

形式 32k 24k 20k 16k 8k
Radiance (.hdr) 32768×16384 24000×12000 20000×10000 16384×8192 8192×4096
OpenEXR (.exr) 32768×16384 24000×12000 20000×10000 16384×8192 8192×4096
PNG 32768×16384 24000×12000 20000×10000 16384×8192 8192×4096
PNG + MMD 32768×16384 24000×12000 20000×10000 16384×8192 8192×4096

※ 16k / 8k サイズは ++skies; 017 以降 16384×8192 / 8192×4096、000〜016 は 16000×8000 / 8000×4000 です。

※ MMD 16k / HDR 16k 以上は非常に大きなメモリ領域を消費します。ご注意ください。

※ ray-mmd プラグインと組み合わせて使用する場合は、HDRxxパッケージを推奨します（MMDパッケージではHDRiのメリットが得られません）。
