aokcub::Web プライバシーポリシー

本ページでは，私aokcubが運営するウェブサイトhttps://aokcub.net/（メイン）および https://aokcubcg.github.io/（GitHub Pages 経由のミラー）（以下まとめて本サイト）をご利用いただくにあたっての注意点を記載しています。

アクセスログの収集について

本サイトでは，サーバの稼働状況やアクセス傾向の分析，また本サイトの利便性向上のために，ご利用される皆様のアクセス情報を収集しています。このログにはアクセスページ，アクセス日時，アクセス元IPアドレス，ブラウザ等の閲覧環境，等が含まれ，住所，氏名，電話番号，メールアドレス等，個人に直接紐づく情報は含まれません。

また，本サイトは GitHub Pages 上でホストされているため，GitHub 社がアクセスログを取得する場合があります。詳しくは GitHub プライバシーステートメント（外部サイト）をご参照ください。

Cookieの利用について

Google Analytics

本サイトでは，Google社から提供されるCookieを用いて，本サイトへのアクセス情報を収集しています。これらの情報は本サイトのアクセス傾向の分析，利便性向上に使用されます。
Google Analyticsの詳細，Google社のプライバシーポリシーに付いては，以下のページをご覧ください（外部サイト）。
Google Analytics利用規約
Google プライバシーポリシー

もし，あなたがGoogle社によるアクセス情報の収集を望まない場合は，下記のプラグインをインストールすることで収集を停止することができます。
Google アナリティクス オプトアウト アドオン（外部サイト）

Silktide Cookie Consent

上記Google AnalyticsによるCookie使用の通知を目的として，Silktide社が提供するCookie Consent（旧 Insites Cookie Consent）のCookieを使用しています。
本Cookieは，アクセス時に表示されるポップアップでOKボタンを押さない限り保存されません。
Silktide社プライバシーポリシー（外部サイト）

外部サービスの利用について

本サイトでは，上記Cookie発行元のほか，以下の外部サービスを利用しています。これらのサービスを提供する各事業者にも，閲覧時にIPアドレス等のアクセス情報が送信されます。

Google Fonts

本サイトでは，Google社が提供する Google Fonts から Web フォントを読み込んでいます。フォント取得時に Google 社に閲覧者のIPアドレス等が送信されます。詳細は前述の Google プライバシーポリシー（外部サイト）をご参照ください。

YouTube 動画埋め込み

本サイトの制作物紹介ページには，Google LLC が運営する YouTube の動画を埋め込んでいる箇所があります。当該ページを表示した時点で，視聴の有無に関わらず YouTube 側で Cookie の発行・閲覧情報の取得が行われる場合があります。詳細は Google プライバシーポリシー（外部サイト）をご参照ください。

X (Twitter) 埋め込みボタン

本サイトの一部ページには，X Corp. が提供する Tweet ボタン・Follow ボタンを設置しています。これらのボタンを表示した時点で X 社による Cookie 発行・閲覧情報の取得が行われる場合があります。詳細は X プライバシーポリシー（外部サイト）をご参照ください。

外部CDN

本サイトでは，Cookie Consent や Web フォント等の取得のために，Cloudflare 社が運営する cdnjs および Google 社が運営する Google Fonts CDN を利用しています。これらの CDN へのアクセス時に，各事業者へ閲覧者のIPアドレス等のアクセス情報が送信されます。

素材ファイルの配信について

本サイトで配布している ++skies; および ++spheres; の素材ファイルは，Amazon Web Services, Inc. の Amazon S3 に保管されており，ダウンロードリンクをクリックすると S3 から直接配信されます。配信時に AWS 側で IP アドレス等のアクセス情報が記録される場合があります。詳細は AWS プライバシー通知（外部サイト）をご参照ください。

収集情報の管理について

上記手段で収集した情報は，各項で記載した目的にのみ使用され，個人の識別に利用されることはありません。また，以下の場合を除き，訪問者が特定される形で第三者に開示することはありません。

  • 法的根拠に基づく請求がある場合
  • 当該情報の提供者からの承諾がある場合

通信暗号化について

本サイトでは，すべてのページにおいて，SSL証明書を用いて通信の暗号化を行っております。
